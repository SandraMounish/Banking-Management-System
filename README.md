# 🏦 Bank Management System

A simple **console-based Bank Management System** developed using **Core Java** and basic **Object-Oriented Programming (OOP)** concepts.

The application allows users to create bank accounts, deposit money, withdraw money, check account balances, and display all accounts.

## 📌 Features

* Create a bank account
* Deposit money
* Withdraw money
* Check account balance
* Display all accounts
* Menu-driven console interface
* Basic balance validation

## 🛠️ Technologies Used

* Java
* Core Java
* OOP Concepts
* Scanner
* Arrays

> **Note:** This project uses a normal Java array to store accounts. It does not use `ArrayList`, databases, external libraries, or packages.

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Bank-Management-System.git
```

### 2. Open the Project

Open the project using any Java IDE such as:

* Eclipse
* IntelliJ IDEA
* VS Code

### 3. Compile the Program

Open the terminal inside the project folder and run:

```bash
javac BankManagementSystem.java
```

### 4. Run the Program

```bash
java BankManagementSystem
```
